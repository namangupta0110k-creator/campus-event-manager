# Campus Event Management

## Description
Campus Event Management is a simple project designed to maintain
information about events organized on campus. It provides details
about upcoming events, their dates, and the organizers responsible
for managing them.

## Files
- `README.md` - Project title and description.
- `events.txt` - List of campus events and their dates.
- `organizers.txt` - List of event organizers and their responsibilities.

## Purpose
The purpose of this project is to organize campus event information
in a simple and structured way.

## Usage
1. Clone the repository to your computer.
2. Read `events.txt` to view campus events and their dates.
3. Read `organizers.txt` to view organizer details and responsibilities.
4. Refer to `project-notes.md` for the project summary and planned features.
